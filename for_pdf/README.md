# PDF Table Picker

`pdf` 폴더의 PDF 파일을 파일명 오름차순으로 무한 캔버스에 펼치고, 자동 감지된 표를 선택해 Excel로 내보내는 Electron 앱입니다.

## 실행

상위 프로젝트에서 의존성을 설치한 상태라면 이 폴더에서 다음 명령으로 실행합니다.

```powershell
npm start
```

앱에서 **PDF 불러오기**를 누르면 PDF 페이지 렌더링과 표 감지가 시작됩니다. 첫 실행은 페이지 이미지를 만들기 때문에 시간이 조금 더 걸리며, 이후에는 렌더링 캐시를 재사용합니다.

## 사용법

- 빈 캔버스를 드래그해 이동하고 휠로 확대/축소합니다.
- 각 PDF 창은 제목 표시줄로 이동하고 오른쪽 아래에서 크기를 조절합니다.
- PDF 페이지에서 원하는 표 영역을 드래그합니다.
- 영역 위에서 자동, 선 기반, 텍스트 기반 중 하나를 골라 **파싱**합니다.
- 선이 있는 표는 선 기반이 정확하고, 선이 없는 표는 텍스트 기반이 유리합니다.
- 선택한 표 오른쪽 위에 그룹 번호를 입력하면 다른 PDF의 같은 그룹과 Excel 행이 맞춰집니다.
- **Excel 내보내기**로 선택한 표를 파일별 가로 열에 배치해 저장합니다.
