# 보고서 캔버스

이 폴더에서 `npm start`로 실행합니다. 처음 설치할 때는 `npm install`을 먼저 실행합니다.

## 폴더 안내

| 폴더 | 역할 |
| --- | --- |
| `src/main` | Electron 진입점, preload, 보고서 프레임 이동, preload 번들 생성 |
| `src/renderer` | 화면 HTML, 화면 제어, 목차 패널, 표 검색 UI, CSS |
| `src/toc` | 목차 모델, 추출, 세션 관리 |
| `src/tables` | 표 검색, 규칙, DOM 분석, 파서와 워커 |
| `src/laya` | Laya 연결과 Python 워커 |
| `src/shared` | 보고서 모델과 비동기 작업 유틸리티 |
| `data` | 보고서 목록과 검색·Laya 설정 |
| `.runtime` | 실행 시 생성되는 Electron 캐시와 보고서용 preload 번들 |
| `artifacts` | `npm start -- --capture-on-load` 검증 결과가 생성되는 위치 |

보고서 목록은 `data/reports.json`에서 수정합니다. 검색 버튼 옆에서 `기존 규칙` 또는 `Laya choice`를 선택합니다. 기본값은 기존 규칙이며 Python을 실행하지 않습니다. Laya choice는 단계마다 후보 중 하나를 반드시 선택합니다. Python·모델 경로와 제한 시간은 `data/laya-config.json`에서 관리합니다.

앱 루트는 Electron 진입점 위치를 기준으로 계산합니다. 데이터·캐시·진단 결과는 앱 루트에 두고, 모듈과 화면 자원은 각 소스 파일을 기준으로 참조합니다. 보고서용 preload는 샌드박스에서 실행할 수 있도록 시작 시 번들로 생성합니다.

## 표 검색 방식

Laya choice는 목차를 계층별로 선택하고, 필요한 경우 본문 제목을 선택한 다음 해당 구간의 표를 비교합니다. 기존 규칙의 포함·제외 키워드, 연결·별도 조건 및 유사도 검사를 통과한 표만 Laya 후보가 됩니다. 다른 목차 전체로 검색 범위를 자동 확장하지 않습니다.

목차 선택과 표 선택은 별도 단계입니다. 선택 확률은 후보 사이의 상대적인 선택 확률이며 정답을 보장하거나 일치 여부를 확정하는 점수가 아닙니다.

Laya는 단계별 영어 지시문을 사용합니다. 목차·본문 제목 선택지는 한국어 원문 제목을 유지합니다. 표 선택은 기존 규칙을 통과한 후보의 문자 셀만 행별 텍스트로 보내며, 숫자로만 된 셀과 긴 주변 문맥은 제외합니다. 당기·전기와 연결·별도 표시, 본문 순서는 유지하고 선택지는 짧은 후보 이름으로 구성합니다. 전체 입력은 SDK 토크나이저로 검사하며, 한도 초과 시 후보나 텍스트를 임의로 자르지 않고 한도·후보 수·대략적인 텍스트 토큰 수를 표시합니다. `python tests/laya_choice_model_check.py`는 재구성한 목차 후보로 기존 입력과 수정 입력을 실제 모델에서 비교합니다. 이 명령은 모델 준비와 추론 시간이 필요합니다.

실제 코웨이 보고서에서 확보한 목차 후보로 비교하려면 `python tests/laya_choice_model_check.py --toc-json tests/fixtures/dart-toc-20260323000924.json`을 실행합니다. 이 테스트는 최상위 목차 선택만 검증합니다.

## Laya 준비와 검증

Laya 사용에는 Python과 `pip install laya`로 설치한 패키지가 필요합니다. 앱은 Laya choice를 사용할 때 Python 프로세스를 시작하고 모델을 준비합니다. 앱 재시작 후에는 모델을 메모리에 다시 로드하지만 패키지를 재설치하지 않습니다. `modelPath`가 비어 있으면 Hugging Face 캐시를 확인하고 필요한 모델 파일을 내려받습니다. 다운로드된 모델 폴더를 지정하면 해당 로컬 모델을 사용합니다.

`npm test`는 JavaScript 회귀 테스트를, `python tests/laya_worker_test.py`는 모델을 로드하지 않는 입력 구성·토큰 한도·응답 검증 테스트를 실행합니다. 현재 JavaScript 23개와 Python 9개, 총 32개가 통과했습니다. 실제 모델의 최상위 목차 선택은 별도로 검증했으며, 이번 표 텍스트 방식의 실제 보고서 검색 정확도는 추가 확인이 필요합니다.
