# DART 보고서 목록 수집 앱

DART 사이트에서 직접 검색하고 필터링한 공시보고서 목록을 모으는 Windows 데스크톱 앱입니다. 왼쪽에는 실제 DART 사이트, 오른쪽에는 수집한 보고서 목록이 표시됩니다.

## 설치와 실행

Node.js 22 이상이 필요합니다. 저장소를 받은 후 프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
npm ci
npm start
```

의존성을 설치한 뒤에는 `start.cmd`를 더블클릭해 실행할 수도 있습니다. 최초 실행 시 인터넷 연결이 필요합니다.

## 보고서 수집하기

1. 왼쪽 DART에서 회사명을 검색하고 기간, 공시 유형, 최종보고서 등 원하는 조건을 직접 설정합니다. 예를 들어 코웨이를 검색하고 정기공시의 사업보고서와 최종보고서를 선택합니다.
2. 앱 상단의 **보고서 추출 OFF** 버튼을 눌러 **ON**으로 바꿉니다.
3. DART 사이트의 **검색** 버튼을 누릅니다. 토글을 켜기 전에 완료된 검색 결과는 수집되지 않으므로 다시 검색해야 합니다.
4. 오른쪽 목록에서 공시대상회사, 보고서명, 접수일자와 보고서 링크를 확인합니다. `[기재정정]` 같은 보고서명 표시도 유지됩니다.
5. 결과가 여러 페이지라면 DART에서 직접 다음 페이지로 이동합니다. ON 상태에서 받은 결과는 계속 누적되며 같은 접수번호는 중복으로 추가되지 않습니다.
6. 수집을 멈추려면 토글을 **OFF**로 바꿉니다. 기존 목록은 유지됩니다.

회사의 보고서를 검색하는 흐름을 기준으로 동작합니다. 현재 수집 대상은 DART의 `/dsab007/detailSearch.ax` 검색 응답입니다. 전체 통합검색 등 다른 검색 방식은 해당 응답을 사용하지 않을 수 있습니다. 검색 조건 설정과 페이지 이동은 사용자가 직접 수행합니다.

## 목록 관리

- **보고서 링크 열기**: 기본 브라우저에서 DART 원문 보고서를 엽니다. 버튼에 마우스를 올리면 링크 주소를 확인할 수 있습니다.
- **삭제**: 해당 보고서를 목록에서 제거합니다. 삭제 이력은 남기지 않으며 다음 검색 결과에 포함되면 다시 수집됩니다.
- **전체 비우기**: 수집 목록을 모두 비우고 빈 상태를 저장합니다.
- **수집 건수**: 현재 목록에 남아 있는 보고서 수를 표시합니다.

DART 사이트 자체에서 보고서를 누르면 별도 공시뷰어 창이 열릴 수 있습니다.

## DART 화면 확대·축소

먼저 **왼쪽 DART 화면을 클릭**하여 키보드 포커스를 둡니다.

| 단축키 | 동작 |
| --- | --- |
| `Ctrl + -` | 축소 |
| `Ctrl + 0` | 기본 배율인 100%로 복원 |
| `Ctrl + Shift + =` (`Ctrl + +`) | 확대. 키보드 배열에 따라 `Ctrl + =`도 사용할 수 있습니다. |

Electron/Chromium의 기본 단축키를 사용합니다. 별도 배율 버튼, `Ctrl + 마우스 휠` 기능, 앱 자체 배율 저장 기능은 구현하지 않았습니다. 단축키가 반응하지 않으면 DART 화면을 다시 클릭하고 입력하세요.

## 자동 저장과 복원

수집·삭제·전체 비우기마다 프로젝트 폴더의 `data/reports.json`에 마지막 목록이 자동 저장됩니다. 다음 실행 시 같은 파일을 자동으로 읽습니다. 추출 토글은 매번 OFF로 시작합니다.

```json
{
  "version": 1,
  "reports": [
    {
      "rcpNo": "20220816001433",
      "url": "https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20220816001433",
      "reportName": "[기재정정]사업보고서 (2021.12)",
      "companyName": "코웨이",
      "receivedDate": "2022.08.16"
    }
  ]
}
```

저장 파일이 없으면 빈 목록으로 시작합니다. 저장은 순서대로 처리하고 임시 파일을 작성한 후 교체합니다. 로컬 수집 데이터와 `node_modules`, 개발 검증용 `work` 폴더는 Git에 포함하지 않습니다.

## 문제 해결

- **DART 접속 실패**: 일시적인 연결 오류에는 최대 두 번 자동 재시도하며 마지막 시도는 공시 검색 화면으로 연결합니다. 계속 실패하면 **DART 다시 연결**을 누르세요. 검색 조건은 초기화되지만 수집 목록은 유지됩니다. 일반 브라우저에서도 DART 접속이 가능한지 확인하세요.
- **ERR_EMPTY_RESPONSE**: DART 요청에는 앱 이름과 Electron 제품명이 없는 Chromium 형식의 User-Agent를 적용했습니다. 이전 버전을 실행 중이라면 완전히 종료하고 최신 코드로 다시 실행하세요.
- **수집되지 않음**: 추출 ON 상태에서 DART 검색 버튼을 다시 누르세요. 회사명 검색 방식과 위에 설명한 대상 응답을 사용하는지 확인하세요.
- **저장 실패**: 프로젝트 폴더의 쓰기 권한과 디스크 여유 공간을 확인하세요.
- **저장 파일 손상**: 원본 보호를 위해 자동 저장이 중단됩니다. 앱을 종료하고 `data/reports.json`을 백업한 뒤 수정하거나 다른 이름으로 옮기고 다시 실행하세요. 파일을 옮기면 빈 목록으로 시작합니다.
- **응답 수집 연결 끊김**: 앱을 재실행하세요. DART 개발자 도구를 열면 수집용 디버거 연결이 끊길 수 있습니다.

## 현재 범위와 검증

현재 버전은 보고서 목록 수집·편집·저장까지 지원합니다. 자동 페이지 이동, 여러 보고서 동시 보기, 본문 데이터 추출, Excel 내보내기는 아직 구현하지 않았습니다.

```powershell
npm test
```

코웨이 사업보고서 10건의 파싱, 중복 제거, 삭제 후 재수집, 저장·복원, 손상 파일 보호, 연결 재시도와 User-Agent 처리를 검증합니다. 실제 DART 접속과 코웨이 사업보고서 수집도 확인했습니다.

### 앱 실행과 화면

| 파일 | 역할 |
| --- | --- |
| `main.js` | Electron 앱의 시작점입니다. 창과 DART 화면을 만들고 응답 수집, 목록 관리, 저장 및 화면과의 통신을 연결합니다. |
| `preload.js` | 화면에서 사용할 수 있는 목록 조회·추출 토글·삭제·재연결 등의 통신 기능을 제공합니다. |
| `index.html` | 앱 상단 버튼과 오른쪽 수집 목록 영역의 HTML 구조입니다. 왼쪽 DART는 별도의 웹 화면으로 표시됩니다. |
| `renderer.js` | 수집 목록과 상태 메시지를 화면에 표시하고 버튼 클릭을 처리합니다. |
| `style.css` | 앱 화면의 배치, 색상, 버튼과 보고서 카드의 스타일입니다. |
| `start.cmd` | 현재 폴더에서 `npm start`를 실행하는 Windows 실행 파일입니다. |

### 기능 모듈 (`lib/`)

| 파일 | 역할 |
| --- | --- |
| `lib/capture.js` | DART 검색 요청과 응답을 감지하고, 추출 ON/OFF 상태에 따라 응답 본문을 읽습니다. |
| `lib/connection.js` | DART 접속, 일시적인 연결 오류 재시도 및 검색 화면으로의 대체 연결을 처리합니다. |
| `lib/reports.js` | 검색 결과 HTML에서 보고서 정보를 추출하고 접수번호 기준으로 목록을 합쳐 중복을 제거합니다. |
| `lib/store.js` | JSON 파일 읽기, 저장 형식 확인, 순차 저장 및 임시 파일 교체를 처리합니다. 손상된 기존 파일은 보호합니다. |
| `lib/user-agent.js` | DART 요청의 User-Agent에서 앱 이름과 Electron 제품명을 제거하고 Chromium의 플랫폼·버전 정보를 유지합니다. |

### 테스트 (`test/`)

| 파일 | 역할 |
| --- | --- |
| `test/collector.test.js` | 보고서 정보 추출, 중복 제거, 삭제 후 재수집, 저장·복원 및 응답 수집 토글 처리를 검사합니다. |
| `test/connection.test.js` | 접속 재시도, 검색 화면 대체 연결, 오류 처리 및 User-Agent 변환을 검사합니다. |

`test/`는 `npm test`를 실행할 때 사용하는 개발용 검사 코드입니다. 앱 실행에는 필요하지 않지만 기능 수정 후 기존 동작을 확인하기 위해 저장소에 포함합니다.

### 설정과 로컬 폴더

| 파일·폴더 | 역할 |
| --- | --- |
| `package.json` | 프로젝트 이름, 실행·테스트 명령과 Electron·Cheerio 의존성을 정의합니다. |
| `package-lock.json` | 설치할 의존성 버전을 기록합니다. `npm ci`는 이 파일을 기준으로 설치합니다. |
| `README.md` | 설치, 사용법, 문제 해결 및 프로젝트 구성 안내입니다. |
| `.gitignore` | Git에 올리지 않을 로컬 데이터, 의존성, 검증 파일 등을 지정합니다. |
| `data/` | 현재 수집 목록인 `reports.json`과 저장 중 임시 파일을 보관합니다. 필요할 때 자동 생성되며 다른 컴퓨터로 목록을 옮기려면 `reports.json`을 별도로 복사합니다. |
| `node_modules/` | npm이 설치한 의존성이 들어 있습니다. 직접 수정하지 않으며 삭제했다면 `npm ci`로 다시 설치합니다. |
| `work/` | 접속 비교와 실제 앱 실행 검증 등에 사용한 개발용 임시 스크립트입니다. 앱 실행과 `npm test`에는 필요하지 않으며 저장소를 내려받아도 포함되지 않습니다. |
| `.git/` | Git이 커밋 이력과 원격 저장소 정보를 관리하는 숨김 폴더입니다. 앱 실행과는 관계없습니다. |
