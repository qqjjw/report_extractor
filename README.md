# report_extractor

보고서 표 추출 프로젝트입니다. 실행 파일은 용도별 브랜치에서 관리합니다.

- [old_version](https://github.com/qqjjw/report_extractor/tree/old_version): HTML 보고서 표 추출 앱. `for_pdf`는 포함하지 않습니다.
- [pdf_version](https://github.com/qqjjw/report_extractor/tree/pdf_version/for_pdf): PDF 표 추출 앱과 관련 자료를 담은 `for_pdf` 폴더.

`main` 브랜치에는 이 README만 유지합니다.
