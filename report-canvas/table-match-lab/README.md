# 감가상각 표 매칭 실험 앱

기존 캔버스 앱과 독립된 로컬 Electron 테스트 앱입니다. 상위 폴더의 `2023.html`과 `2022.html`을 읽습니다. 원본 파일과 reports.json은 수정하지 않고, 네트워크·AI·벡터 DB 없이 두 파일의 구조 차이를 비교합니다.

## 실행

이 폴더에서 `npm start` 또는 `start.cmd`를 실행합니다. 현재 프로젝트의 설치된 Electron과 Cheerio를 사용할 수 있습니다. 별도로 복사한 환경에서는 먼저 `npm install`을 실행하세요. 검증은 `npm test`입니다.

## 사용

왼쪽 목록의 **양쪽 원문으로 이동**을 누르면 대응 후보 표로 동시에 이동합니다. 감가상각 행은 초록색, 해당 표 전체는 초록 테두리, 선택한 표는 주황 테두리로 표시합니다. 원문 영역은 각자 가로·세로 스크롤할 수 있습니다. 합격·불합격은 실행 중 화면에만 표시하며 자동 학습하거나 저장하지 않습니다. **원본 다시 분석**은 파일을 다시 읽고 판정을 초기화합니다.

## 실험 방법

1. 번호가 붙은 유형자산 제목을 찾고 다음 같은 수준 이상 제목까지 범위를 제한합니다. 2022년 `2.9 유형자산` 회계정책과 `10. 유형자산` 데이터 주석은 별도 구간입니다. 2023년 파일에서는 제공된 본문의 끝까지 사용합니다.
2. 범위 안에서 `감가상각` 또는 `감가상각비, 유형자산`처럼 감가상각 행·셀을 찾습니다. 감가상각누계액은 다른 항목으로 취급합니다.
3. 표 직전 문단·안내 표에서 당기/전기와 단위를 읽습니다. 계정과목별 상각 설명 아래의 비용표는 셀에 감가상각이라는 단어가 없어도 문맥 근거로 포함합니다.
4. 기초·취득·감가상각·처분·손상·기말 항목을 정리해 변동표를 비교합니다. 계약 해지 항목은 사용권자산을 구분하는 구조 단서로 사용합니다. 비용표와 변동표를 서로 매칭하지 않습니다.
5. 같은 상대 기간·표 역할의 후보를 공통 행/열 항목 수로 정렬합니다. 2023년 당기·전기 비용표가 2022년 한 표에 합쳐져 있으면 두 개를 같은 표에 대응시킵니다. 금액 일치는 매칭 점수에 사용하지 않습니다.

이 실험은 **당기끼리, 전기끼리의 표 역할 대응**입니다. 2023년 전기와 2022년 당기의 동일 회계기간·동일 금액을 대조하는 기능은 아닙니다. 파일 이름은 입력 식별자이며 표의 실제 회계기간으로 자동 확정하지 않습니다.

점수는 확률이 아닙니다. 사용권자산 구조 단서와 구간 경계 규칙은 두 예시에 맞춘 실험 규칙이며 다른 회사·양식에 대한 일반화는 검증하지 않았습니다. 여러 후보가 있는 경우 높은 점수부터 대응하므로 사람이 원문과 문맥을 검수해야 합니다. 조건과 근거는 `matcher.js`, 화면은 `renderer.js`와 `style.css`, 원본 경로는 `main.js` 상단에서 확인합니다. 원본 CSS는 파일에 없으므로 앱의 간단한 표 스타일로 표시하며 행·셀·병합 구조와 값은 유지합니다.
