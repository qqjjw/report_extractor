# DART 보고서 무한 캔버스

기존 수집 앱과 독립적으로 실행하는 Electron 앱입니다. 상위 폴더의 `data/reports.json`에 기록된 모든 DART 보고서를 실제 웹 화면으로 열어 가로 캔버스에 배치합니다.

## 실행

Node.js 22 이상에서 이 `report-canvas` 폴더를 터미널로 열고 실행하세요.

```powershell
npm install
npm start
```

설치 후 `start.cmd`를 더블클릭해도 됩니다. 수집 앱을 동시에 실행할 필요는 없지만 `../data/reports.json` 파일은 필요합니다. 별도 설정 파일이나 파일 선택 단계는 없습니다.

## 사용법

- 최초 실행: JSON 순서대로 1,060×1,400 크기의 보고서를 가로 한 줄로 엽니다.
- 빈 공간 드래그: 캔버스를 상하좌우로 이동합니다.
- 제목 표시줄 드래그: 보고서를 원하는 위치로 옮깁니다.
- 사이트 안: DART 목차 클릭, 본문 스크롤과 링크를 평소처럼 사용합니다.
- 오른쪽 아래 손잡이: 해당 카드의 크기를 조절합니다. 최소 크기는 480×360입니다.
- 이 크기를 전체에 적용: 해당 카드의 너비·높이를 모든 보고서에 적용합니다. 위치는 유지되므로 겹치면 나란히 정렬을 누르세요.
- 나란히 정렬: 현재 순서·각 카드 크기를 유지해 가로 한 줄로 재배치하고 첫 보고서로 이동합니다.
- 기간 ↑ / 기간 ↓: 접수일자가 아닌 보고서명의 `(2025.12)` 같은 대상 연월로 정렬합니다. 같은 기간은 원본 JSON 순서, 기간이 없는 보고서는 마지막입니다.
- − / + / 100%: 캔버스 배율을 25~150%로 조절합니다. 사이트 안의 휠은 본문 스크롤입니다.
- 목록 새로고침: JSON을 다시 읽고 모든 사이트를 처음부터 엽니다. 직접 옮긴 배치·크기·배율은 기본 상태로 돌아갑니다. 파일이 잘못되면 현재 화면은 유지하고 오류를 표시합니다.
- 다시 열기: 특정 보고서의 접속 실패 시 그 사이트만 다시 엽니다.

파일 변경은 새로고침 전까지 반영되지 않습니다. 배치·크기·배율은 저장하지 않습니다. 원본 JSON은 읽기만 하며 앱 종료 시에도 수정하지 않습니다.

## 자원 사용과 제한

사이트는 최초에 최대 3개씩 동시에 불러오며, 화면 밖에 있어도 닫지 않습니다. 보고서 수가 많으면 메모리 사용량과 첫 로딩 시간이 증가합니다. 모든 로드가 끝난 뒤 목록 새로고침을 사용할 수 있습니다. 일부 보고서 접속 실패는 다른 보고서 사용을 막지 않습니다. DART의 팝업은 별도 창으로 열릴 수 있습니다.

본문 추출, 데이터 묶기, Excel 내보내기, 전체 보기, 배치 저장은 이 버전에 포함하지 않습니다.

## 코드 구조와 변경 위치

| 파일 | 확인할 내용 |
| --- | --- |
| `main.js` 상단 | 원본 JSON 경로, 도구 모음·제목·하단 높이, 동시 로드 수, 접속 제한 시간, User-Agent 제품명 |
| `main.js` 처리 로직 | JSON 새로고침, 실제 WebContentsView 생성·배치, 사이트 로드, 제목 드래그·크기 조절 연결 |
| `lib/scene.js` 상단 | 기본·최소 카드 크기, 가로 간격, 배율 범위, 보고서명 기간 규칙, 허용 DART 호스트 |
| `lib/scene.js` 처리 로직 | JSON 검증, 기간 정렬, 가로 배치, 크기 적용 |
| `preload.js` | 로컬 화면과 메인 프로세스 통신. DART 사이트에는 이 API를 제공하지 않습니다. |
| `index.html`, `background.html`, `renderer.js` | 상단 명령과 빈 공간 캔버스 조작 |
| `card.html`, `card.js` | 카드 제목·상태·다시 열기·전체 크기 적용·크기 조절 |
| `overlay.html`, `overlay.js` | 웹 화면 사이를 넘나드는 드래그 입력 처리 |
| `style.css` | 화면 스타일. 제목·하단 높이는 main.js 값과 함께 확인합니다. |
| `test/scene.test.js` | JSON·정렬·가로 배치·크기·배율 검증 |
| `package.json`, `package-lock.json`, `start.cmd` | 의존성과 실행 명령 |

기존 파일의 상단 입력값과 처리 로직을 한국어 주석으로 나눕니다. 상시 상세 로그는 남기지 않습니다. 문제가 생겼을 때 실제 요청과 응답을 확인하고 관련 코드를 점검합니다.

## 문제 해결과 검증

- 파일 없음: 수집 앱에서 보고서 목록을 저장하고 `main.js`의 `REPORTS_FILE`을 확인하세요.
- JSON 형식 오류: 수집 앱의 version 1 저장 형식과 필수 필드를 확인하세요. 새로고침 실패는 현재 화면을 닫지 않습니다.
- DART 접속 실패: 해당 카드에서 다시 열기를 누르고 일반 브라우저 접속도 확인하세요. 실제 앱 이름이 요청에 포함되는 문제는 User-Agent에서 앱 이름·Electron 제품명을 제거하여 대응합니다.
- 기간 순서 이상: 보고서명과 `lib/scene.js`의 `PERIOD_PATTERN`을 확인하세요. 접수일자로 정렬하지 않습니다.
- 이동·크기·사이트 배율 이상: `main.js`의 `layout()`과 제스처 처리를 확인하세요.

```powershell
npm test
```

실제 접속 확인은 스크립트로 main.js만 불러오는 대신 `npm start`와 같은 패키지 진입점으로 수행하세요. 검증용 `work/`와 `node_modules/`는 Git 대상에서 제외됩니다.

### 캔버스 스크롤바와 보고서 목록

캔버스 하단 가로 스크롤바와 오른쪽 세로 스크롤바로 전체 시점을 이동합니다. 보고서 내부 스크롤은 해당 사이트만 이동합니다. 빈 공간 드래그도 같은 캔버스 시점을 조작합니다.

좌측 목록에서 보고서를 누르면 현재 배율과 크기를 유지하며 보고서 중심으로 이동하고, 겹친 보고서는 앞으로 가져옵니다. 회사명·보고서명·접수일자·로딩 상태를 확인할 수 있습니다. 상단 **목록 접기 / 펼치기** 버튼과 패널 오른쪽 경계선 드래그로 표시 및 폭을 조절합니다. 기본 폭은 280px이며 200~500px 범위에서 캔버스 공간을 400px 이상 남깁니다. 패널을 조절하거나 창 크기를 바꿔도 보던 캔버스 중심과 사이트 상태는 유지됩니다.

목록 새로고침은 선택을 초기화하고 모든 사이트를 다시 엽니다. 현재 실행 중의 패널 폭과 접힘 상태는 유지하지만 재실행 시에는 저장되지 않습니다. 스크롤바 이동은 현재 범위 안에서 멈춥니다. 빈 공간 드래그는 무한 이동을 유지하며, 화면이 경계를 벗어날 때만 범위를 확장합니다. 보고서 이동·크기 변경은 보고서 주변 화면 한 개만큼의 여유를 반영하고, 정렬·배율 변경·새로고침 시 범위를 다시 계산합니다.

| 증상 | 확인할 코드 |
| --- | --- |
| 스크롤 범위·음수 좌표·중앙 이동 오류 | `report-canvas/lib/scene.js`의 경계·범위·중앙 계산 |
| 패널 폭·화면 중심·웹 화면 겹침 오류 | `report-canvas/main.js`의 패널 입력값과 layout |
| 목록 순서·선택·스크롤바 표시 오류 | `report-canvas/renderer.js`, `index.html`, `style.css` |
| 패널 드래그·화면 통신 오류 | `report-canvas/preload.js`, `overlay.js`, `main.js` |

새로고침은 도구 모음 오른쪽의 경고 색상 버튼을 **1.5초 동안 누르고 있어야** 실행됩니다. 하단 진행 표시가 완료되기 전에 놓거나 버튼 밖으로 이동하면 취소합니다. 키보드 Space·Enter도 같은 방식이며, 포커스를 잃으면 취소합니다. 새로고침은 모든 사이트의 진행 상태와 배치·크기·배율을 초기화합니다. 누르기 시간과 보호 동작은 `report-canvas/renderer.js`, 버튼 배치는 HTML·CSS, 스크롤 범위는 `report-canvas/lib/scene.js`와 `main.js`에서 확인합니다.
